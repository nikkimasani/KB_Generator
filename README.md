# KB Generator

A single-page tool (`index.html`) for drafting knowledge-base articles in Salesforce's plain-text format, so they can be pasted straight into a Salesforce Knowledge article.

Open `index.html` in a browser — no install or build step.

**Status:** early standalone version (2025). A later copy lives in [sql-generator](https://github.com/nikkimasani/sql-generator) as `KB Generator.html`.
